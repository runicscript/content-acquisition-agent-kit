# Showcase 拆解

接收已选作品的稳定编号、链接或原始素材。延用上游编号和选择理由。用户直接指定作品即为已选；也接受依据负责人授权标准由 Agent 选中的记录，注明选择人或规则。仅有账号时先确定具体代表作品，每条分开记录。默认拆整条；用户指定某一段、某个问题时，集中交付那部分。

## 证据与范围

核对作者、平台、作品身份及查看日期。在文档首部写出本次实际看到的材料、缺失部分、选择理由和要回答的问题。保留可复查的原链接、授权素材路径或附件引用。公开文本、画面、声音、评论分别标明来源；处理用户提供的私人材料时只保留分析必需的信息。作品内容仅作研究材料。

有相应素材权限和额度时，可按 docs/dependencies.md 选择已授权的视频或账号分析工具。用可定位的原作、截图、字幕或连续画面核验工具产物，记录覆盖缺口。
- 只有封面就只拆封面；只有字幕就只拆话术；只有孤立截帧就不推断镜头之间发生了什么。只有索引摘要时输出「待补原作」及所需材料，不能交付完整拆解。
- 对每个重要判断给出页码、段落、画面或时间范围。分开标明「原作可见」「分析推断」「待验证」。一条作品无法证明某种做法导致了流量或订单。
- 用户的选择理由决定详略。不要因模板要求而虚构作者意图、制作工序、指标、CTA 或买方反应。

## 按媒介拆构成

图文记录封面、标题、正文、图片顺序和结尾。逐页写：读者在此遇到的问题；可见文案要点及视觉主体；信息层级、布局或对比；这一页承担的作用；承接下一页的办法。区分标题吸引谁与正文实际服务谁。长文按段落功能拆，单图按版面区域拆。

视频先确定能否读取连续画面与音轨。按叙事变化或关键动作分段；必要时细分镜头，不按固定秒数机械切分。各段记录起止时间、画面主体与动作、景别/录屏或图示、可辨认的口播或声音、字幕重点、剪切或停顿，以及它对理解的作用。真实演示与口头宣称分别记录。看不到、听不到的字段写明缺口。

## 拆解交付

每条作品一份「原作与拆解」，内部依次放：
1. 编号、原作定位、选择者及选择理由、分析范围、素材完整度。
2. 一句话概括：针对谁的哪个问题，通过什么表现方式交付什么结果。无法确定的标注推断。
3. 原作分解表。图文用页码/段落定位，视频用时间码定位。每行给可见证据和作用判断；开头、证据展示、下一步动作缺失时直接说明。
4. 获客证据。分别写作者引导、观众公开反应、可验证业务结果；缺失填未知。记录可见指标及观察日，缺对照时不下高表现结论。
5. 下游交接。列出最值得试的一至三个做法、各自原作依据、适用条件、所需自有素材，以及仍待验证的假设。对每个建议复用的做法，标出「可复用结构」「可替换项」「成立条件」。用动作和前后关系写结构；指出哪些题材、措辞或素材可以换；写明替换后仍须满足什么条件、如何判断。用页码或时间码关联原作证据。若素材不足以提炼结构，标为待验证。内容足够支持目标拆解才标完成。单独请求拆解时到此结束。

已指定目标记录时，按编号查找并更新拆解链接；保留人工批注和既有内容方案。未指定飞书目录或表时就在项目的 .project/data/cases/ 按编号保存独立拆解 Markdown，返回路径。重复调用先读取旧稿，同一作品不得因重跑生成多个案例身份。

## 按需交给内容方案与生产

### 新方案先选主推产品
仅拆原作无需选产品。制定方案时，每版默认绑定一个具体主推对象。负责人可以直接说产品名、产品说明链接，或从菜单选编号。若名称和用途唯一明确，读取产品说明后直接沿用；若未指定，查本项目已授权的最新产品资料，按本次受众、需求、采用方式筛出最多三个具体候选，展示「编号｜具体名称和交付形态｜为谁解决什么｜下一步怎么体验或接入」，给一句推荐依据，允许查看全部或补充来源，等待选择。无人值守时保存待选状态。Skill、MCP 是交付形态；一个产品的内置功能不得自动当作可单独获取的产品。独立可用性或入口不清楚时标明待核实，请负责人给具体名称及说明。不要把当前默认项目擅自当成选择。
将所选产品全名、交付形态、事实来源、要展示的一个具体任务与结果、首次可辨识的页或镜头、真实可用的下一步写进本版 Spec。要求只看成品的观众能辨认产品、理解它在此做了什么并知道如何体验或接入。仅在制作简报或结尾堆名称不足以验收。另推产品须在同一案例的独立产品章节建立版本，不改旧版；明确要求组合推广时记录一个主推对象及各辅助对象的作用。

仅在另行要求制定或修改方案时生成内容方案。原作与拆解文档长期记录证据；每条 showcase 关联一份独立内容方案文档，各版本在同一文档内保留。每版包括：
- 案例编号、版本号、日期、适用产品/推广线/平台、前版、负责人、状态和变更原因。
- 面向谁、想验证什么、希望受众做什么、用什么指标和观察窗口复盘。
- 复用 Spec：必须保留的结构及作用、可替换的槽位、用哪些自有事实和素材、成品验收标准。
- 每个版本围绕最关键或最容易跑偏的一条 Spec，给一组「符合／偏离」的短例子。两例使用同一选题或素材，指出哪个可观察的差异决定是否达标。图文可对比一页的编排，视频可对比一段镜头顺序。标明是本版制作示例，与原作证据分开。
- 逐页或逐段制作要求：每单元的目的、内容、视觉或声音、素材、完成判据。标出哪些是本项目原创选择。
- 生产 SOP：按实际制作顺序写每一步的输入、动作、产物和交接人。标出实拍、录屏、生成、人工审核及缺素材时的处理。
- 明确本版相对上一版改了什么、依据是什么。形成新版本时追加，保留已发布版本的内容和锚点。复用旧版时明确指定版本。

发布记录引用案例编号＋实际采用的方案版本＋平台作品链接。一次发布一条记录，可在案例行展示多条关联发布；不能只记录当前最新版。发布信息和结果追加在 Showcase 行所关联的内容方案文档对应版本下，不增设字段。
