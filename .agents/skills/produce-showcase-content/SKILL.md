# 内容生产

接到制作请求时，使用 manage-showcases 定位案例、拆解和内容方案文档。读取指定版本、推广线、本次选题、目标平台和可用素材。以该版 Spec 与 SOP 为准，核对受众、预期动作、产品事实及验收判据。若项目有多个可用版本且用户未指定，先确认；仅当负责人明确委托制定首版时才先建立 V1。换选题可沿用同版。产品截图、演示结果和功效数字须有依据；演示素材标作演示。缺少决定真实性的素材时明确指出需要哪一件。

## 按版本核验主推产品
直接沿用指定版本绑定的具体主推产品，不重复问。若用户明确改推另一产品，或旧版本只有“推一个 Skill / MCP”而无具体对象，则按 showcase-breakdown 的产品选择规则补齐；冻结版本需另立版本并关联原版。完成选择前不启动媒体生成。根据已核实资料选择表现形式：终端产品可演示一次使用；独立 Skill 可展示具体任务的输入与输出；MCP 服务可演示一次调用与返回。用已有演示或明确标注的示例，不能虚构接口名、效果或体验地址。
图文验收逐页文案和配图提示词，指出哪一页让读者认出产品、看到作用和下一步；将这些要求完整交给制作 Agent。视频先检查分镜，再核对成片中实际可读或可听见的名称、演示结果及行动入口，交付时指出对应镜头或时间码。仅出现在提示词、内部脚本或片尾标识不足以证明作用。无法核对的项目列为待审，缺失项应先修正。

## 图文制作包

交付一个完整可复制的提示词包。制作 Agent 单凭这个包和列明的素材即可执行，避免“见前面讨论”一类无可用上下文的引用。只引用负责人可提供给制作 Agent 的素材；清楚标出随包需附的文件。
1. 制作简报：方案版本、平台、受众、主题、产品事实、获客动作、输出页数与画幅、统一的视觉与文字风格。
2. 文案：写出本次标题、正文、各页上版文字与结尾动作；附给制作 Agent 的文案生成或排版指令，说明必须保留的事实、可调整之处。若用户只要文案提示词，则将文案要求与必用信息直接写入指令。
3. 配图：逐页编号，各给一条可独立使用的提示词，包含本页目的、主体与场景、构图、素材引用、文字区域、精确上版文案和跨页一致性要求。需要可读界面或精确文字时让制作 Agent 使用提供的截图并排版文字，勿让绘图模型虚构界面。
4. 交付前核对页数、图文对应、手机端可读性、方案要求和行动入口。将提示词包交给负责人转交制作 Agent；图文分支止于此，不调用 LibTV 生图。

## 视频：直接制作可审的成片

1. 内部编排脚本与镜头。按所选版本确定时长、画幅、每段画面/动作、时间、口播/字幕、参考素材和衔接。区分真实产品演示和可生成的场景。参考图和配音输入只取本次作品所需内容。
2. 使用当前 Agent 已获授权的 LibTV MCP 或其他具备所需能力的媒体工具。读取 docs/dependencies.md 中的视频接入。若当前环境只能写脚本或分镜，保留制作包并注明成片待接入。先读连接器返回的 instructions 与实时工具说明，按 doctor 等可用只读能力确认身份、项目及生成/合成能力。按连接器的额度和授权规则预检；在指定或明确属于本次的新项目内制作。普通视频走媒体生成能力，音乐驱动广告等特殊需求才调用相应专项流程。
3. 用内部镜头计划直接生成。支持一次输出完整视频时优先走该路径；需要分镜生成时，用可用的组接或导出能力按顺序合成，并按方案加入声音、字幕。异步任务记录项目和任务 ID，等待原任务完成；中断后先恢复查询。遇到已受理但结果未知，不重复提交扣费任务。
4. 回读成品资源并验证有单条可播放视频、时长画幅符合方案，检查关键画面、字幕和音轨。不能检查的项目列为待人工核验。只有片段、任务号或空画布时，继续处理能完成的合成；确无合成能力时交代具体缺口及已生成资源，不能标作成片。
5. 向负责人交付可播放的成片链接或文件、采用的方案版本及审片重点。停在待审，不自动发布。

## 记录

在本次使用的内容方案版本下追加一条制作记录（选题、日期、交付形式、提示词包或成片位置、待审状态）。成品和记录一一对应；对同一制作任务的重试复用已有记录。若链接有时效，保留项目及素材定位以便找回。使用原表的内容方案文档，不增列、不改有效评级，不覆盖已确认的版本正文。无法回写时，先交付实际产物并说明记录状态。
